## 基于 5 层架构 + SDK 生态的平台设计

## 📐 目标架构：5 层分离

```
┌─────────────────────────────────────────────────┐
│                  Agent Core                     │  ← Layer 1: 智能决策层
│       Planner / Executor / Replan / Memory      │
└────────────────────┬────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────┐
│            Capability Registry                  │  ← Layer 2: 能力注册层
│  browser / git / file / coding / office / db    │
└────────────────────┬────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────┐
│              Skill Platform                     │  ← Layer 3: 技能平台层
│    Tool / Workflow / Prompt / Resource          │
└────────────────────┬────────────────────────────┘
                     │
┌────────────────────▼────────────────────────────┐
│         Python Runtime Manager                  │  ← Layer 4: 运行时管理层
│       venv / Worker / IPC / Sandbox             │
└────────────────────┬────────────────────────────┘
                     │
              ┌──────┴──────┐
              ▼             ▼
        MCP Adapter    Native Python                  ← Layer 5: 执行层
              │             │
        External MCP   本地高性能
```

### 核心理念

#### 1. **分层解耦**
- **Layer 1 - Agent Core**: 负责任务规划、执行、重新规划、记忆管理，与具体能力实现解耦
- **Layer 2 - Capability Registry**: 能力注册中心，统一管理所有可用能力（browser/git/file/coding/...）
- **Layer 3 - Skill Platform**: 技能平台，提供 Tool（工具）、Workflow（工作流）、Prompt（提示词）、Resource（资源）四种能力封装
- **Layer 4 - Python Runtime Manager**: 统一管理 Python 运行时（venv 隔离、Worker 池、IPC 通信、沙箱安全）
- **Layer 5 - Execution Layer**: 双执行路径
  - **MCP Adapter**: 标准互操作，跨进程/跨语言/跨设备
  - **Native Python**: 本地高性能，直接执行

#### 2. **Skill 的双重路径**

```
                  Skill
            ┌──────┴──────┐
            │             │
     Python Native       MCP
            │             │
       本地高性能      标准互操作
            │             │
            └──────┬──────┘
                   ↓
        Capability Registry
                   ↓
                Agent
```

- **Python Native**: 高性能场景（文件处理、代码分析、数据计算）
- **MCP**: 跨进程/跨语言/远程服务（浏览器控制、Git 服务、数据库连接）
- **自动选择**: Skill Platform 根据能力声明自动选择最优路径

#### 3. **Agent Core 语言无关性**
- Python Skills 通过 Worker + IPC/MCP 独立运行
- 即使 Agent Core 未来迁移到 Java/C++/TypeScript，Skills 无需重写
- Skill 生态长期稳定

## 🔄 当前架构 vs 目标架构

### 当前架构问题

```typescript
// 当前：工具直接注册到 Agent
electron/main/agent/
├── tools.ts              # 50+ 内置工具硬编码
├── python.ts             # Python 工具独立进程
├── mcp.ts                # MCP 工具独立管理
└── workspace.ts          # 工作区操作硬编码
```

**问题**：
1. ❌ 内置工具硬编码，无法热插拔
2. ❌ Python/MCP/内置工具三套体系，重复逻辑
3. ❌ 新增工具需修改核心代码
4. ❌ 无统一的 Skill 生命周期管理
5. ❌ MCP 只能作为输入，无法作为 Skill 的输出

### 目标架构优势

```typescript
// 目标：分层解耦
electron/main/
├── agent/
│   ├── core.ts                 # Agent Core (规划/执行/记忆)
│   ├── skill-manager.ts        # Skill 生命周期管理
│   └── skill-runtime.ts        # Python Skill Runtime
├── skills/                     # Skill 插件目录
│   ├── file-operations/        # 文件处理 Skill
│   │   ├── skill.json
│   │   ├── index.py
│   │   └── requirements.txt
│   ├── browser-automation/     # 浏览器 Skill
│   └── git-operations/         # Git Skill
└── mcp/
    └── adapter.ts              # MCP 双向适配器
```

**优势**：
1. ✅ Skill 热插拔，用户可安装/卸载
2. ✅ 统一的 Python Runtime，一套进程管理
3. ✅ MCP 双向适配：Skill 可调用 MCP，也可暴露为 MCP
4. ✅ 核心代码稳定，扩展不改核心
5. ✅ Skill 独立版本管理、依赖隔离

#### 1.3 Python Skill Runtime

**文件**: `electron/main/agent/skill-runtime.ts`

```typescript
import { spawn, type ChildProcessWithoutNullStreams } from 'node:child_process'
import { randomUUID } from 'node:crypto'
import path from 'node:path'
import fs from 'node:fs'
import type { SkillInstance } from '../../shared/skill.js'

type SkillRequest = {
  skillId: string
  tool: string
  args: Record<string, unknown>
  workspace?: string
  mcpContext?: {
    availableServers: string[]
    // MCP 调用上下文
  }
}

type SkillResponse = {
  output: unknown
  mcpCalls?: Array<{
    server: string
    tool: string
    args: Record<string, unknown>
    result: unknown
  }>
  elapsedMs: number
}

type RunningSkill = {
  skillId: string
  process: ChildProcessWithoutNullStreams
  pending: Map<string, {
    resolve: (value: SkillResponse) => void
    reject: (error: Error) => void
    timer: NodeJS.Timeout
  }>
}

export class PythonSkillRuntime {
  private running = new Map<string, RunningSkill>()
  private maxConcurrent = 8
  
  constructor(
    private skillManager: SkillManager,
    private mcpManager: AgentMcpManager
  ) {}
  
  // 执行 Skill 工具
  async execute(
    request: SkillRequest,
    signal: AbortSignal,
    timeoutMs = 60000
  ): Promise<SkillResponse> {
    signal.throwIfAborted()
    
    const skill = this.skillManager.get(request.skillId)
    if (!skill) throw new Error(`Skill not found: ${request.skillId}`)
    
    if (!skill.enabled) throw new Error(`Skill disabled: ${request.skillId}`)
    
    // 启动或复用进程
    let running = this.running.get(request.skillId)
    if (!running) {
      running = await this.startSkill(skill)
      this.running.set(request.skillId, running)
    }
    
    // 发送请求
    const requestId = randomUUID()
    
    return new Promise<SkillResponse>((resolve, reject) => {
      const timer = setTimeout(() => {
        running!.pending.delete(requestId)
        reject(new Error(`Skill execution timeout: ${request.skillId}`))
      }, timeoutMs)
      
      const abort = () => {
        running!.pending.delete(requestId)
        clearTimeout(timer)
        reject(new Error('Task cancelled'))
      }
      
      signal.addEventListener('abort', abort, { once: true })
      
      running!.pending.set(requestId, { resolve, reject, timer })
      
      // JSON-RPC 格式
      const message = JSON.stringify({
        id: requestId,
        skillId: request.skillId,
        tool: request.tool,
        args: request.args,
        workspace: request.workspace,
        mcpContext: request.mcpContext
      }) + '\n'
      
      running!.process.stdin.write(message, 'utf8', error => {
        if (error) {
          running!.pending.delete(requestId)
          clearTimeout(timer)
          reject(new Error(`Failed to send request: ${error.message}`))
        }
      })
    })
  }
  
  // 启动 Skill 进程
  private async startSkill(skill: SkillInstance): Promise<RunningSkill> {
    const executable = process.env.MYPLANE_PYTHON || 
                      (process.platform === 'win32' ? 'python' : 'python3')
    
    const entryPath = path.join(skill.path, skill.manifest.entry)
    
    if (!fs.existsSync(entryPath)) {
      throw new Error(`Skill entry not found: ${entryPath}`)
    }
    
    const child = spawn(executable, [entryPath, '--runtime-mode'], {
      cwd: skill.path,
      env: {
        ...process.env,
        SKILL_ID: skill.manifest.id,
        SKILL_VERSION: skill.manifest.version,
        PYTHONIOENCODING: 'utf-8',
        PYTHONUTF8: '1'
      },
      stdio: ['pipe', 'pipe', 'pipe'],
      windowsHide: true
    })
    
    const running: RunningSkill = {
      skillId: skill.manifest.id,
      process: child,
      pending: new Map()
    }
    
    // 处理 stdout（JSON-RPC 响应）
    let buffer = ''
    child.stdout.on('data', (chunk: Buffer) => {
      buffer += chunk.toString('utf8')
      
      let newline = buffer.indexOf('\n')
      while (newline >= 0) {
        const line = buffer.slice(0, newline).trim()
        buffer = buffer.slice(newline + 1)
        newline = buffer.indexOf('\n')
        
        if (!line) continue
        
        try {
          const response = JSON.parse(line)
          const pending = running.pending.get(response.id)
          
          if (pending) {
            clearTimeout(pending.timer)
            running.pending.delete(response.id)
            
            if (response.error) {
              pending.reject(new Error(response.error))
            } else {
              pending.resolve(response)
            }
          }
        } catch (error) {
          console.error(`Failed to parse skill response:`, line, error)
        }
      }
    })
    
    // 处理 stderr
    child.stderr.on('data', (chunk: Buffer) => {
      console.error(`[Skill ${skill.manifest.id}]`, chunk.toString('utf8'))
    })
    
    // 进程退出
    child.on('close', (code) => {
      console.log(`Skill process exited: ${skill.manifest.id}, code=${code}`)
      this.running.delete(skill.manifest.id)
      
      // 拒绝所有待处理请求
      for (const [id, pending] of running.pending) {
        clearTimeout(pending.timer)
        pending.reject(new Error(`Skill process exited: code=${code}`))
      }
      running.pending.clear()
    })
    
    return running
  }
  
  // 停止 Skill 进程
  async stop(skillId: string): Promise<void> {
    const running = this.running.get(skillId)
    if (!running) return
    
    this.running.delete(skillId)
    
    // 拒绝所有待处理请求
    for (const [id, pending] of running.pending) {
      clearTimeout(pending.timer)
      pending.reject(new Error('Skill stopped'))
    }
    running.pending.clear()
    
    // 终止进程
    running.process.kill('SIGTERM')
    
    // 等待最多 3 秒
    await new Promise<void>(resolve => {
      const timer = setTimeout(() => {
        running.process.kill('SIGKILL')
        resolve()
      }, 3000)
      
      running.process.once('close', () => {
        clearTimeout(timer)
        resolve()
      })
    })
  }
  
  // 停止所有
  async stopAll(): Promise<void> {
    await Promise.all(
      Array.from(this.running.keys()).map(id => this.stop(id))
    )
  }
}
```

### Phase 2: MCP Adapter 双向适配

#### 2.1 MCP Adapter 架构

**文件**: `electron/main/mcp/adapter.ts`

```typescript
import type { SkillManager } from '../agent/skill-manager.js'
import type { PythonSkillRuntime } from '../agent/skill-runtime.js'
import type { AgentMcpManager } from '../agent/mcp.js'

export class McpAdapter {
  constructor(
    private skillManager: SkillManager,
    private skillRuntime: PythonSkillRuntime,
    private mcpManager: AgentMcpManager
  ) {}
  
  // 方向 1: Skill 调用 MCP
  // Skill 通过 Runtime 发起 MCP 调用
  async callMcpFromSkill(
    skillId: string,
    mcpServer: string,
    tool: string,
    args: Record<string, unknown>,
    signal: AbortSignal
  ): Promise<unknown> {
    // 验证 Skill 权限
    const skill = this.skillManager.get(skillId)
    if (!skill) throw new Error(`Skill not found: ${skillId}`)
    
    const allowedServers = [
      ...(skill.manifest.capabilities.mcp?.required || []),
      ...(skill.manifest.capabilities.mcp?.optional || [])
    ]
    
    if (!allowedServers.includes(mcpServer)) {
      throw new Error(
        `Skill ${skillId} not permitted to call MCP server ${mcpServer}`
      )
    }
    
    // 查找 MCP Tool
    const mcpTool = this.mcpManager.findTool(mcpServer, tool)
    if (!mcpTool) {
      throw new Error(`MCP tool not found: ${mcpServer}/${tool}`)
    }
    
    // 执行 MCP 调用
    return await mcpTool.execute(args, signal)
  }
  
  // 方向 2: 将 Skill 暴露为 MCP Tool
  // Agent 看到的是 MCP Tool，实际执行的是 Skill
  exposeSkillsAsMcp(projectId: string): ToolSpec[] {
    const specs: ToolSpec[] = []
    
    for (const skill of this.skillManager.getEnabled()) {
      // 跳过未声明 exposeMcp 的 Skill
      if (!skill.manifest.capabilities.exposeMcp) continue
      
      for (const tool of skill.manifest.capabilities.tools || []) {
        specs.push({
          definition: {
            type: 'function',
            function: {
              // 工具名称带 Skill 前缀
              name: `skill_${skill.manifest.id}_${tool.name}`,
              description: `[Skill: ${skill.manifest.name}] ${tool.description}`,
              parameters: tool.parameters
            }
          },
          source: `skill:${skill.manifest.id}`,
          risk: this.calculateRisk(skill, tool),
          timeoutMs: 60000,
          
          execute: async (args: Record<string, unknown>, signal: AbortSignal) => {
            // 准备 MCP 上下文
            const mcpContext = {
              availableServers: this.mcpManager
                .list()
                .filter(s => s.status === 'connected')
                .map(s => s.id)
            }
            
            // 执行 Skill
            const response = await this.skillRuntime.execute(
              {
                skillId: skill.manifest.id,
                tool: tool.name,
                args,
                mcpContext
              },
              signal
            )
            
            return JSON.stringify(response.output)
          }
        })
      }
    }
    
    return specs
  }
  
  private calculateRisk(
    skill: SkillInstance,
    tool: SkillToolDefinition
  ): 'read-only' | 'high' {
    // 根据权限判断风险
    if (skill.manifest.permissions.fileSystem?.write ||
        skill.manifest.permissions.network) {
      return 'high'
    }
    return 'read-only'
  }
}
```

#### 4.1 Python Skill 基类

**文件**: `skills/_base/skill_base.py`

```python
import sys
import json
import asyncio
from typing import Dict, Any, Optional
from abc import ABC, abstractmethod

class SkillBase(ABC):
    """Skill 基类，所有 Python Skill 继承此类"""
    
    def __init__(self):
        self.skill_id = os.getenv('SKILL_ID')
        self.skill_version = os.getenv('SKILL_VERSION')
        self.mcp_client = None  # MCP 客户端（如果需要）
    
    @abstractmethod
    async def handle_tool_call(
        self,
        tool: str,
        args: Dict[str, Any],
        context: Dict[str, Any]
    ) -> Any:
        """处理工具调用，子类必须实现"""
        pass
    
    async def call_mcp(
        self,
        server: str,
        tool: str,
        args: Dict[str, Any]
    ) -> Any:
        """调用 MCP 服务"""
        if not self.mcp_client:
            raise RuntimeError("MCP client not initialized")
        
        # 通过 Runtime 发起 MCP 调用
        # Runtime 会验证权限并执行
        request = {
            'type': 'mcp_call',
            'server': server,
            'tool': tool,
            'args': args
        }
        
        # 发送到 stdout，Runtime 处理后返回结果
        print(json.dumps(request), flush=True)
        
        # 等待响应（同步阻塞）
        response_line = sys.stdin.readline()
        response = json.loads(response_line)
        
        if response.get('error'):
            raise RuntimeError(response['error'])
        
        return response.get('result')
    
    async def run_runtime_mode(self):
        """Runtime 模式：持久运行，接收 JSON-RPC 请求"""
        while True:
            try:
                line = sys.stdin.readline()
                if not line:
                    break
                
                request = json.loads(line.strip())
                request_id = request['id']
                
                try:
                    result = await self.handle_tool_call(
                        tool=request['tool'],
                        args=request['args'],
                        context={
                            'workspace': request.get('workspace'),
                            'mcpContext': request.get('mcpContext')
                        }
                    )
                    
                    response = {
                        'id': request_id,
                        'output': result,
                        'elapsedMs': 0  # TODO: 计时
                    }
                except Exception as e:
                    response = {
                        'id': request_id,
                        'error': str(e)
                    }
                
                print(json.dumps(response), flush=True)
            
            except Exception as e:
                sys.stderr.write(f"Runtime error: {e}\n")
                sys.stderr.flush()

def main():
    """入口函数"""
    if '--runtime-mode' in sys.argv:
        # Runtime 模式
        skill = YourSkillClass()
        asyncio.run(skill.run_runtime_mode())
    else:
        # CLI 模式（可选）
        pass

if __name__ == '__main__':
    main()
```

```python
import os
import pathspec
from skill_base import SkillBase

class FileOperationsSkill(SkillBase):
    """文件处理 Skill"""
    
    IGNORED = {'.git', 'node_modules', 'dist', '__pycache__'}
    
    async def handle_tool_call(self, tool: str, args: dict, context: dict):
        workspace = context.get('workspace', '.')
        
        if tool == 'list_files':
            return await self.list_files(
                workspace,
                args.get('path', '.'),
                args.get('depth', 4)
            )
        
        elif tool == 'read_file':
            return await self.read_file(
                workspace,
                args['path'],
                args.get('startLine'),
                args.get('endLine')
            )
        
        elif tool == 'search_files':
            return await self.search_files(
                workspace,
                args['query'],
                args.get('path', '.')
            )
        
        else:
            raise ValueError(f"Unknown tool: {tool}")
    
    async def list_files(self, workspace: str, rel_path: str, depth: int):
        """列出文件"""
        base_path = os.path.join(workspace, rel_path)
        if not os.path.isdir(base_path):
            raise ValueError("Not a directory")
        
        result = []
        
        def walk(dir_path: str, level: int):
            if level > depth:
                return
            
            try:
                for entry in os.scandir(dir_path):
                    if entry.name in self.IGNORED:
                        continue
                    
                    rel = os.path.relpath(entry.path, workspace)
                    rel = rel.replace('\\', '/')
                    
                    if entry.is_dir():
                        result.append(rel + '/')
                        walk(entry.path, level + 1)
                    elif entry.is_file():
                        result.append(rel)
            except PermissionError:
                pass
        
        walk(base_path, 0)
        
        return {
            'paths': result[:500],
            'truncated': len(result) > 500
        }
    
    async def read_file(
        self,
        workspace: str,
        rel_path: str,
        start_line: int = 1,
        end_line: int = None
    ):
        """读取文件"""
        file_path = os.path.join(workspace, rel_path)
        
        if not os.path.isfile(file_path):
            raise ValueError("File not found")
        
        if os.path.getsize(file_path) > 2 * 1024 * 1024:
            raise ValueError("File too large (max 2MB)")
        
        with open(file_path, 'r', encoding='utf-8', errors='replace') as f:
            lines = f.readlines()
        
        total = len(lines)
        start = max(1, start_line) - 1
        end = min(total, end_line or start + 200)
        
        text = ''.join(
            f"{i+1}: {lines[i]}"
            for i in range(start, end)
        )
        
        return {
            'path': rel_path,
            'totalLines': total,
            'startLine': start + 1,
            'endLine': end,
            'text': text[:24000]
        }
    
    async def search_files(self, workspace: str, query: str, rel_path: str):
        """搜索文件"""
        # 调用 MCP 服务进行索引搜索（如果可用）
        mcp_context = context.get('mcpContext', {})
        if 'filesystem-indexer' in mcp_context.get('availableServers', []):
            try:
                return await self.call_mcp(
                    'filesystem-indexer',
                    'search',
                    {'query': query, 'path': rel_path}
                )
            except Exception as e:
                # Fallback 到本地搜索
                pass
        
        # 本地搜索实现
        base_path = os.path.join(workspace, rel_path)
        matches = []
        
        for root, dirs, files in os.walk(base_path):
            dirs[:] = [d for d in dirs if d not in self.IGNORED]
            
            for file in files:
                file_path = os.path.join(root, file)
                try:
                    with open(file_path, 'r', encoding='utf-8', errors='ignore') as f:
                        for i, line in enumerate(f, 1):
                            if query.lower() in line.lower():
                                rel = os.path.relpath(file_path, workspace)
                                matches.append({
                                    'path': rel.replace('\\', '/'),
                                    'line': i,
                                    'text': line.strip()[:400]
                                })
                                if len(matches) >= 60:
                                    break
                except:
                    pass
                
                if len(matches) >= 60:
                    break
            
            if len(matches) >= 60:
                break
        
        return {
            'matches': matches,
            'truncated': len(matches) >= 60
        }

    import sys
    from skill_base import main
    main()
```
