# 知识库

## 自动提炼与能力改进

成功执行结束后，知识库根据已有工具结果提炼只读模板，并核对完整的搜索、来源、正文或文件路径证据链。证据足够时自动标记验证通过，仍等待用户启用；证据不足则显示原因，后续成功运行可再次验证。不会为了学习额外联网或重放文件操作，不覆盖用户编辑的版本。已启用方法失败后，若通用查询找到另一有效天气来源，会另存候选供验证，保留旧方法与失败记录。

能力模块在宿主能独立确定正确结果时自动记录回归案例，目前接入独立查询的新任务边界纠正。工具错误、权限拒绝、未知失败与宿主自身规则问题单独记录归因，不伪造模块期望结果。各模块仍受原阈值与每日预算限制；失败生成或未通过验证的候选，分别冷却 1 分钟、5 分钟后重试，总计最多 3 次。重试分析包含之前的失败报告；取消、非模块原因、等待手动发布的合格候选不自动重试。只有通过完整回归、历史回放且确实优于现用版本，才按自动发布开关切换。界面展示触发阻碍、冷却时间、失败归因与自动案例。

入口：设置 → 知识库，与插件菜单并列。全局开关控制经验收集、自动复用和搜索可用性学习；停用时也会清空天气内存缓存。

## 候选、验证与启用

普通任务完成后提炼可复用方法，不因模型宣称成功而启用。工具顺序只作排查记录，不作为方法本身。支持以下模板：

- 天气：城市定位、目标时区日期、每日预报、地点/日期/单位/数值检查。内置程序首次验证成功可自动记录为可用方法。
- 天气网站：从实际读取、包含本次城市、绝对日期和温度信息的网页提取来源域名。按工作目录与来源合并为候选，不保存原 URL 的路径、参数和预报正文。试运行通过并启用后优先在该网站限定搜索新的城市、日期，再读取和核对结果；不会重放浏览历史。网页检查不等于结构化气象校验或人工确认所有事实正确。
- 公开资料查询：按地区搜索主流引擎，选择真实结果链接，读取正文并检查来源和查询相关性。
- 文件查阅：校验原工作目录范围，重新读取指定相对路径。

网页与文件候选在详情页填写本次参数及预期正文片段，点击“试运行并验证”。通过后仍须点击“启用此流程”。联网试运行需勾选本次网络授权，项目禁止联网时不执行；文件试运行须选择产生经验的原项目。输入和预期片段仅用于本次检查，不保存。

天气网站方法填写城市、日期与预期正文片段。当前沿用内置天气解析器支持的中国城市，日期按 Asia/Shanghai 换算；正文需有完整年月日，不能用页面抓取时间代替预报日期。来源方法不可用时交回通用查询。旧天气记录只有工具顺序，无法还原成功网站；转换后须补充已确认有效的来源域名，再试运行验证。界面优先展示来源、方法和校验规则，历史工具顺序收在折叠的排查信息中。

网页流程会去重并按配置的结果上限尝试备用链接（最多 5 个）。页面读取失败、来源不符、正文无关或缺少预期片段时尝试下一条；权限被拒绝立即停止。备用证据通过检查后可继续完成任务，原始失败保留在会话记录中，不额外生成含重复工具的候选。失败试运行的表单输入仅在当前页面保留，便于修正重试。

程序检查证明读取流程和本次证据有效，不证明网页中所有事实正确。未知工具序列只能审阅；包含修改、命令执行或未知工具的任务不收录为可执行经验。

## 编辑与版本

可编辑名称、匹配词、地区、正文来源域名、验证有效期（1–720 小时）和网页读取范围。步骤使用固定模板，不能填入任意代码。编辑后创建新版本、清除认证并暂停复用；可从最近 10 个历史版本恢复为新版本，再次验证。

版本检查覆盖保存、试运行认证、启用和执行；运行期间编辑或停用不会使旧结果认证新版本。旧格式记录迁移为待验证且停用，损坏文件保留并报告错误。

## 聊天复用

按工作目录、任务类别、全部匹配词、地区、来源限制、当前工具、文件/网络权限及有效期匹配。只对简单明确的“搜索…”“读取 文件路径”等输入绑定参数；复杂多步骤请求继续走通用 Agent。

命中后显示采用的流程名称、版本和记录标识，并通过正常工具权限和审批执行。校验结果会报告到会话。明确的来源、正文或结构化数据校验失败会暂停复用；网络故障、拒绝授权、取消、工具不可用、参数不符和任务未完成分别记录为中断，保留原验证与启用状态。保留原验证不会延长其有效期。结果始终来自本次工具调用，经验不提供完成证据或额外授权。详情显示采用次数、最近采用、失败原因及验证到期时间。

内置天气仍可独立处理支持的简单问句；城市或日期缺失时询问，复杂请求或指定其他来源时交给通用 Agent。Open-Meteo 预报经过程序校验，在内存缓存最多 10 分钟，不持久化天气答案。

## 搜索可用性经验

独立于事实验证，按地区与引擎保存最近 24 小时的最多 20 次结果。连续两次失败或空结果才在地区优先组内后移，成功后恢复；所有引擎仍可重试。停用知识库后使用默认地区顺序。菜单底部显示统计及有效期。

TypeScript 旧工具和 Python agent-tools 共用主机端路由记录。搜索引擎返回结果不等于答案正确，仍需读取实际来源。

## 本机数据

Agent 数据目录中的 experience-library.json 保存最多 300 项流程、工作目录哈希、用户编辑的条件、最多 10 个历史版本、统计和验证摘要。search-health.json 仅保存地区、引擎、时间和可用性结果。不自动保存提问、工具参数、预期片段、文件正文或网页答案。不要在自定义流程名称或匹配词中填入敏感信息。

当前仅支持这些模板，不包含文档导入、向量检索或任意任务的自动流程生成；扩展模板需要配套执行器和验证规则。

仅记录的常见只读序列可通过“生成可验证流程”转换：网页搜索、网页读取或浏览器读取组合生成“搜索 → 读取正文”模板；文件查找并读取、多次读取生成“指定路径 → 读取文件”模板；重复天气查询生成天气模板。转换保留原始工具记录、统计、适用条件和历史版本，不执行原始序列。网页模板需要搜索和网页读取工具，文件模板仍限原项目。转换后必须填写当前参数试运行，通过后手动启用。混合网页与文件等没有匹配模板的组合仍只保留记录。

## 未采用原因与运行分类

同类流程匹配时，检查工作目录、验证有效期、启用状态、当前权限、工具、地区、关键词和来源条件。聊天显示最接近流程的未采用原因；详情页保留最近一次匹配的时间与原因（最多记录最接近的三项流程），不保存查询内容和真实目录。无法绑定参数或已有执行计划也会说明。

详情中的原因提供适用条件、试运行、启用或全局开关入口；权限、项目和工具问题给出对应设置位置，不自动扩大权限。编辑后旧版本的匹配提示不再显示。提示反映所标注时间的检查结果，下次查询时重新判断。

运行中断与校验失败分别计数。网络失败的试运行不会覆盖已有认证、延长有效期或关闭流程；明确内容校验失败仍需重新验证。成功验证或成功复用会清除当前异常提示。旧版失败总数按历史记录保留，不推断重分类。

## 相似问法与参数绑定

简单查询支持“搜索 / 搜一下 / 搜一搜 / 查一下 / 查下 / 上网找一下”，以及 search for、look up、find。文件查阅支持“读取 / 查看 / 看一下 / 读一读 / 查阅”，以及 read、show、view。类型识别与实际参数绑定使用同一组规则，查询词和文件路径保持原始大小写，不将这些表达保存为新的流程。

文件名需是明确路径、带扩展名的名称或 README、LICENSE 等常见名称；其他名称或带空格的路径请加引号。例如“请帮我看一下 README.md”“读取文件 「docs/My Notes.md」的内容”。指代不明的“这个文件”、否定、多步骤和限定来源的复杂表述交回通用 Agent，不猜测目标。天气新增“会不会下雨 / 是否下雨 / 需不需要带伞 / 用不用带伞”等问法。

这是保守的表达规则匹配，不是任意语义推断。原有匹配词、来源、地区、工作目录、验证有效期和权限条件仍全部生效。

## 连续查询与验收范围

完整的独立天气提问（包含城市和日期）按当前输入判断任务边界：北京改问成都建立新查询；成都与成都市视为同一地点，同一日期的重新提问替换当前目标，不追加到旧北京任务。历史消息保留，但旧计划与压缩上下文不参与新查询。“继续”“改成成都”“明天呢”等依赖前文的表达仍走原有延续处理。这是保守的查询规则，不是任意主题的语义分类。

只读天气与网页查询不执行本地测试、TypeScript/Python 诊断或修改前基线检查。恢复此前受阻的查询时，误配的项目验收规则及结果保留在排除记录中，继续核对原页面目标；不能用删除项目检查代替页面证据。发布时间必须来自页面，抓取时间不能替代发布时间。代码修改、混合任务和明确要求的项目检查保留原验收路径。

项目检查入口不再按天气、限行等查询主题枚举放行。必须有用户明确要求项目检查、软件修改目标或已发生实际修改的依据；模型生成的 test/diagnostics 规则本身不是依据。即使目标没有查询动词（例如“博物馆开放时间”），无关项目规则也不会阻塞执行。此限制同时作用于计划、工具筛选和评审检查队列；实际写入前仍按修改流程发现规则并记录基线。旧任务无法取得原始目标时保守保留原验收规则。
