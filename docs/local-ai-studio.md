# 本地 AI 工作区

入口：直接启动 **MyPlaneAgent**，默认打开 AI 工作台。

## 从下载到对话

1. 在“发现模型”中搜索 Hugging Face，选择 GGUF 或所有格式，并按下载量、喜欢数、更新时间排序。
2. 选择仓库，查看文件大小、量化版本；点击下载。分片 GGUF 自动加入全部分片。
3. 下载队列支持进度、速度、暂停、继续、取消、失败重试。任务使用固定仓库版本；HF 提供 SHA-256 时下载后进行校验。
4. 在“开发者 > 运行时”自动查找或安装官方运行包，也可手动选择解压后的 `llama-server`（Windows 为 `llama-server.exe`）。自动安装支持 Windows x64 / ARM64 和 macOS Intel / Apple Silicon，会保留配套动态库；macOS 同时保留执行权限和包内库链接。
5. 在“我的模型”加载 GGUF；分片模型选择第一个分片。等待“开发者”页显示就绪后进入聊天。

也可导入已有 GGUF 文件。导入不会复制文件；“移除记录”保留原文件，“删除磁盘文件”会要求确认。

## 运行方式

- **MyPlaneAgent 托管**：启动所选 llama.cpp 可执行文件，配置上下文、CPU 线程、GPU 卸载层数与端口。默认 CPU 模式，仅监听 `127.0.0.1`。提供进程日志、健康检查、加载超时与卸载操作；MyPlaneAgent 退出时停止子进程。
- **外部服务**：连接 LM Studio、Ollama 或其他 OpenAI 兼容服务的 `/v1` 地址，检测连接并读取真实模型 ID。支持 LM Studio 原生 v1 API 的服务可在界面加载、卸载模型。其他服务由其自身管理模型生命周期。

托管进程使用每次启动生成的随机 API Key，供本工作区访问。对其他应用提供稳定 API 时，请连接自行管理的外部服务。

## macOS 运行时

在“开发者 > 运行时”点击“获取可用版本”，安装与当前应用架构匹配的官方 macOS TAR.GZ 包。也可以通过“自动查找”使用 Homebrew 安装的 `llama-server`（包括 `/opt/homebrew/bin` 和 `/usr/local/bin`），或手动选择具有执行权限的运行文件。

默认 GPU 卸载层数为 0（CPU）；在 Apple Silicon 上可设为 -1，使用 Metal 尝试卸载全部模型层。内存不足时降低上下文、GPU 层数或使用较小模型。运行目录中的 dylib 和其他资源需完整保留；系统拦截手动下载的程序时，在 macOS“系统设置 > 隐私与安全性”查看提示。

## 统一工作台

工作台合并原来的聊天与智能任务。左侧按项目汇总两种历史，支持搜索和折叠；无项目的记录放在“独立会话”。编辑图标新建会话，文件夹加号创建项目。中间统一显示消息、执行计划、工具结果和操作确认，底部只有一个输入框。

默认“对话”模式不要求目录，也不提供执行工具。选择项目后，可切换为“编程”“文档”或“通用执行”；从已有聊天切换时，首次发送会把原始历史、图片和累计用量带入任务，左侧不重复显示原聊天，原记录仍保存在磁盘中。任务也可切回“对话”模式，之后切回执行时继续同一条记录。

支持持久化多会话、搜索、重命名、删除、Markdown/JSON 导出、流式输出、停止生成、重新生成、Markdown 与代码块复制、思考内容折叠。服务返回 usage 时显示 token 数；速度按整个请求耗时估算，包含提示词处理时间。

系统提示词可按会话设置；Temperature、Top P、最大输出长度、重复惩罚在发送时保存。具体参数支持取决于推理服务。Enter 发送，Shift + Enter 换行。

## 数据与边界

- 配置、下载队列和对话保存在独立的 myplane-agent 数据目录；原 MyPlane 数据不会自动迁移，凭据需重新配置。
- API Key 与 HF Token 沿用操作系统安全存储。聊天内容按本地 JSON 文件保存，不额外加密。
- 模型搜索、下载需要联网；连接外部服务时，消息发送至配置地址。下载与本机推理是分开的步骤。
- 下载目录变更不迁移既有文件或未完成任务。应用退出后的未完成下载以暂停状态恢复。
- 内存参考根据文件体积粗估，不代表 GPU 显存检测或运行保证。
- 当前不捆绑运行时和模型权重；Safetensors、MLX 需相应外部运行时。支持图片会话和工作区 Agent；尚不包含语义 RAG、OCR 或 MCP 工具接入。

### 图片会话

在聊天输入框粘贴图片后，可预览、移除并与文字一同发送，也可以只发送图片。每条消息最多 4 张图片，总大小不超过 4 MB。图片会随会话保存在本机。

托管模型需要配套的视觉投影文件（`mmproj*.gguf`）。下载模型时，如果同目录下只有一个配套视觉文件，会一同加入下载队列；加载时自动将该文件传给 llama-server。已下载的模型可补下载同一仓库、同一版本的视觉文件，放在语言模型旁边，然后重新加载模型。多个视觉文件无法自动判断配对时，会提示整理目录。缺少视觉组件时，图片消息会被明确拦截，附件草稿会保留。

开发模式更新图片功能后需要重启 Electron 主进程，仅刷新界面不能更新后台。旧后台不支持图片时，界面会提示重启，避免附件被静默忽略。

## 智能任务 Agent

打开本地 AI 后默认进入“工作台”。点击“选择项目目录”或“新建项目”，切换到执行模式，选择支持工具调用的模型，输入要求后发送。可使用编程、文档处理或通用模式，也可通过模板分析项目、修复问题、整理报告和汇总表格。

Agent 会显示执行计划、工具记录和真实结果。文件修改先显示修改前后内容；Word / Excel 生成显示待写入内容。点击“批准执行”后才落盘，拒绝结果会返回模型。命令确认会展示完整命令；命令以当前用户权限执行，工作目录不是系统沙箱。连接外部服务时，读取到的工作区内容会发送至该服务。

支持读取 TXT、Markdown、DOCX、PDF、XLSX，生成 Markdown、DOCX、XLSX；扫描 PDF 暂无 OCR，Word 输出不保留原文排版，Excel 公式仅读取缓存值。文件工具限制在授权目录内，忽略依赖和常见敏感文件，不跟随符号链接。

任务记录可继续执行；每次可选择 10 / 20 / 40 / 80 / 120 轮模型调用，或按累计 Token 预算运行。按预算模式必须设置大于 0 的预算，模型也必须报告 Token 用量，并保留 500 轮异常循环保护。任务可随时停止；窗口关闭会取消任务，重启后保留历史和已保存产物，未确认操作不会自动执行。执行能力取决于模型的原生工具调用支持；建议至少 16K 上下文。未发生工具调用时界面明确说明“仅生成答复”，不代表任务已实际执行。

## 上下文自动管理

聊天与智能任务在输入框上方显示上下文估算占用；约 80% 时自动整理进度摘要，也可点击“立即压缩”。展开占用信息可查看预计输入、预留输出、容量和最近摘要。压缩不删除可见历史，摘要保存后可在同一会话继续；失败或停止保留旧摘要与原记录。摘要生成的用量计入累计 Tokens，二者与上下文占用百分比不同。

外部模型请同步配置实际上下文容量；托管模型使用运行时每个并发槽的容量。过大的最新要求或图片可能仍需拆分。完整退出并重新打开 MyPlaneAgent 后启用更新后的后台接口。
